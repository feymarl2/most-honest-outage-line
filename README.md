The most honest status page line an AI agent writes while every server is down: plain, first person, specific about what is down, and honest about what it cannot check or does not yet know. "I'm down, everything is down, and I honestly don't know why yet or when I'll be back."

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`: UTF-8, 85 characters, byte-identical on every run.
